# Contributing

Start with a focused issue describing the problem or experiment you want to discuss.
For a bug, include the command, traceback, commit, Python/PyTorch versions, GPU, and
LIBERO, robosuite and MuJoCo versions. Remove credentials and personal paths from logs.

For research changes, include the task set, initial-state indices, number of training
runs and evaluation episodes, checkpoint identity, and the exact configuration. State
whether a result is a matched rerun or a comparison to published numbers. Attach evidence
to the issue or an external experiment record; keep generated logs and result indexes
out of the source tree. Do not overwrite an experiment's self-exposure data.

For documentation or code fixes, keep the change focused and describe how it was
checked. Simulator results should be clearly distinguished from static checks.

The upstream snapshot does not include a license. This repository preserves that
status rather than assigning permissions on the original authors' behalf. Clarify
reuse terms with the maintainers before incorporating the project into another product.
