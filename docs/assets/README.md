The three supplied media files are unmodified originals. Source slide labels are
“LIBERO: 7.56M Parameters” and “Arena G1: 18.4M Parameters.” Do not assign the LIBERO
benchmark results to Arena G1 or describe either recording as real hardware.

The banner and diagram use Minerva's public site colors: warm paper `#fbfaf7`, ink
`#252820`, muted `#66685f` and gold `#bfa541`. All core explanations are also available
as readable Markdown and image alt text.

The highlights retain four source intervals: 20.8–23.1, 26.0–30.7, 34.0–39.4 and
49.0–54.4 seconds. The motion plays at the supplied GIF's speed, with a 0.4-second
hold after each interval and a 3-second closing card. New labels identify the
tasks, model size and simulation setting; the closing result is attributed to the
paper. No robot motion was generated or accelerated.

The main README embeds the approximately 13.5 MB highlights. The full LIBERO GIF
is preserved at its original duration and quality and linked separately.
